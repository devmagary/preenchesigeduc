Como instalar no Edge Canary (Android) via .crx

  1. Baixe o arquivo preenche-sigeduc-edge-mobile.crx no botão acima.
  2. No Edge Canary Android, abra Configurações → Sobre o Microsoft Edge e toque 5 vezes no número da versão para ativar as Opções do desenvolvedor.
  3. Entre em Opções do desenvolvedor → Extension install by crx (ou Instalar extensão por .crx) e selecione o arquivo baixado.
  4. Acesse o portal sigeduc.educacao.ba.gov.br e toque no botão flutuante Preenche SIGEduc.

Como instalar no Chrome Desktop / Mises / Lemur

  1. Baixe e descompacte preenche-sigeduc-chrome.zip (no Mises/Lemur você também pode carregar o .zip diretamente em Extensões).
  2. Abra chrome://extensions, ative o Modo do desenvolvedor e clique em Carregar sem compactação (PC) ou +(from .zip) (Android).
